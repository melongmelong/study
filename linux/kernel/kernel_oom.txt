관련용어/개념
  mmu vs nommu(mmu가없는 => virtual -> physical address변환안되는 메모리관리)
  virtual address vs physical adddress
  paging 
  page : kernel에서는 physical memory상에서의 page를 의미함!. 즉 개념적으로 page frame을 의미.
  huge page : 말그대로 한개의 메모리 페이지크기를 크게 잡는 메카니즘. TLB hit ratio를 높여서 결국엔 성능향상이 목적임.(TLB는 한정된 자원이므로 페이지가 크면 TLB에 항목이 적게 들어갈 것이고, 하나의 항목이 커버하는 영역도 크므로 hit ratio가 높아진다로 보면 될 듯.)
  zone : 사용목적에 따라 page(=page frame)들을 그룹화한 것을 zone이라함.(ex. DMA zone, HIGHMEM zone).
          추후 필요시 각 zone에서 page를 할당받아서 매핑해서 사용하는 개념이라고 보면 되겠다.
  node : NUMA에서, 각 memory bank(하드웨어적으로 메모리의 한 영역이라고 보면 될 듯. 하드웨어적으로 위치가 달름. 그래서 뱅크마다 접근속도등이 다를 수 있다). 각 node마다 독립적인 zone이 존재함.
